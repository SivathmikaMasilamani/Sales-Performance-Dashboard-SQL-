# Sales Performance Dashboard (SQL)

## Project Overview

The Sales Performance Dashboard is a SQL-based project designed to analyze and monitor sales data. The database stores information about salespersons, products, and sales transactions, enabling businesses to evaluate performance and generate valuable insights.

## Objectives

* Manage salesperson information.
* Store product details and categories.
* Track sales transactions.
* Analyze sales performance using SQL queries.
* Generate business insights through data analysis.

## Database Tables

### Salespersons

Stores information about sales representatives:

* Salesperson ID
* Salesperson Name
* Region

### Products

Stores product information:

* Product ID
* Product Name
* Category

### Sales

Stores sales transaction details:

* Sale ID
* Salesperson ID
* Product ID
* Quantity Sold
* Sale Amount
* Sale Date
